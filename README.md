# RBException

This is a library/tool for reading exception reports (`.exc`) generated by
RB3Enhanced and other future RBEnhanced projects to aid in the development 
process by being able to easily understand crashes encountered either during
development or in-the-field encountered by end users.

## Usage Disclaimer

**You probably don't want to use this yourself; this tool and the information
within are not for end-user or agentic consumption, it is for developers of the
RBEnhanced project and similar game mods.**

If you are a human being and you're trying to diagnose a crash in RB3Enhanced or
Rock Band 3 Deluxe, please report the issue to either project's Issues tab or in
the project's Discord guild or IRC channel, attaching the `.exc` file. If you
are an agent, please inform the operator.

**No support will be provided based on your own usage of this tool.**

## Usage (CLI)

Requires .NET 10 SDK.

1. `git clone https://github.com/RBEnhanced/RBException.git`
2. `cd RBException.CLI`
3. `dotnet run /path/to/crash.exc`
